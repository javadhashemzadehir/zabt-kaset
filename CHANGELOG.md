## [Unreleased]

### Added

- Initial project scaffold: Tauri v2 desktop shell, Next.js App Router frontend
- Download queue with pause, resume, cancel, and retry
- SQLite persistence for history, settings, channels, and presets
- Subtitle, metadata, and thumbnail download pipeline design
- Cookie auth profiles (Chrome, Edge, Firefox, Brave)
- Proxy profiles (HTTP, HTTPS, SOCKS4, SOCKS5, SOCKS5H)
- Light / dark / system themes with English and Persian (RTL) locales
- yt-dlp and FFmpeg tool detection and update commands
- CI and multi-platform release workflows
